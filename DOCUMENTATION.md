# SmartLoan AI — Final Year Project Documentation

## 1. Abstract
SmartLoan AI is a full-stack, ML-powered loan eligibility decision-support
system. It combines a Node.js/Express web application with a Python
FastAPI machine-learning microservice to provide applicants with an
explainable eligibility prediction, financial-health analysis, and
what-if scenario simulation, while giving administrators a full
application-management, analytics, and model-governance suite.

## 27. Recommendation Engine
`services/recommendationService.js` — affordability-capped EMI

## 28. Scenario Simulation
What-If Simulator (`/loan/simulate/:predictionId`) — live re-prediction
via `/predict/simulate`, with Scenario History (save/delete).

## 29. Anomaly Detection
Rule-based (extreme income/loan ratio, duplicate/repeated
applications) + Isolation Forest (statistical outlier) — flags, not
fraud accusations.

## 30. Security
bcrypt, express-session + connect-mongo, Helmet, express-rate-limit,
express-validator, custom input sanitization, custom CSRF
(double-submit token), secure cookies, environment variables, safe
error messages (no stack traces to users), Audit Trail, Security
Monitoring.
